Gallery

A simple React gallery app built with React Hooks that fetches image data from an API and displays it as a gallery on the page. This project demonstrates the use of React’s useState and useEffect hooks to fetch and render data dynamically.

🚀 Features

✔ Built with React functional components
✔ Uses Hooks (useState, useEffect)
✔ Makes API requests to fetch image data
✔ Dynamic UI with images rendered from data
✔ Easy to customize and extend

📦 Technologies Used

React js

JavaScript (ES6+)

Fetch / Axios

TailwindCSS for styling


Images, API data and React components are organized under src/ for clarity.

🛠 Installation

Clone the repository

git clone https://github.com/Umar01116/Gallery-.git


Navigate to project directory

cd Gallery-


Install dependencies

npm install


Start the development server

npm run dev


Open in browser

http://localhost:3000


📌 API Integration

This project fetches image URLs from an API and displays them.

✔ You can replace the default API with any other image source
✔ Handles data fetching and rendering using React Hooks
✔ Use Axios or Fetch based on preference
